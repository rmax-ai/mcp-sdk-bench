# mcp-sdk-bench

Executable benchmark comparing **FastMCP 4.x**, **Google ADK's MCP integration**, and the **official MCP Python SDK v2** — protocol coverage, developer ergonomics, runtime behavior, extensibility, interoperability, and effect on real agent behavior.
